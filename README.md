# DSA Striver Sheet Solutions (HackerRank)

Automated HackerRank Striver DSA Problem Solver & GitHub Tracker repository.

## 🚀 Terminal Usage (Fully Offline / Standalone)

Run commands directly in your terminal (PowerShell, Command Prompt, or Bash):

```bash
# Check current progress dashboard
python solve.py --status

# Solve next pending problem, create files, commit & push directly to main
python solve.py
```
