# Solve Me First

## Problem Summary
Calculate the sum of two integers `a` and `b` provided as input.

## Approach & Logic
- Read two integers `a` and `b`.
- Use the standard addition operator `+` to compute `a + b`.
- Return the sum.

## Complexity Analysis
- **Time Complexity:** $\mathcal{O}(1)$ — Arithmetic addition occurs in constant time.
- **Space Complexity:** $\mathcal{O}(1)$ — No extra memory allocations required.
