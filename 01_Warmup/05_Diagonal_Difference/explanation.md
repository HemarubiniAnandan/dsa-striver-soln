# Diagonal Difference

## Problem Statement & URL
- **URL:** https://www.geeksforgeeks.org/problems/diagonal-difference/1
- **Topic:** 01_Warmup
- **Difficulty:** Easy

## Approach & Logic
Iterate through matrix diagonal indices: primary diagonal (i, i) and secondary diagonal (i, n-1-i). Return absolute difference.

## Complexity Analysis
- **Time Complexity:** O(N)
- **Space Complexity:** O(1)
