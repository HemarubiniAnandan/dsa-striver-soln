# Palindrome Number

## Problem Information
- **URL:** https://www.geeksforgeeks.org/problems/palindrome-string0817/1
- **Topic:** 01_Basics
- **Difficulty:** Easy

## Approach & Logic
Compare string S with its reverse S[::-1]. Return 1 if equal, 0 otherwise.

## Complexity Analysis
- **Time Complexity:** O(|S|)
- **Space Complexity:** O(1)
