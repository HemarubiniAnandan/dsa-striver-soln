# Reverse Bits

## Problem Information
- **URL:** https://www.geeksforgeeks.org/problems/reverse-bits1615/1
- **Topic:** 01_Basics
- **Difficulty:** Easy

## Approach & Logic
Extract LSB of X and push into result res using bit shifts across 32 iterations.

## Complexity Analysis
- **Time Complexity:** O(1)
- **Space Complexity:** O(1)
