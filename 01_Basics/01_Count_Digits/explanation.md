# Count Digits

## Problem Information
- **URL:** https://www.geeksforgeeks.org/problems/count-digits5716/1
- **Topic:** 01_Basics
- **Difficulty:** Easy

## Approach & Logic
Iterate through digits of N as string. If digit is non-zero and divides N, increment count.

## Complexity Analysis
- **Time Complexity:** O(log10 N)
- **Space Complexity:** O(1)
