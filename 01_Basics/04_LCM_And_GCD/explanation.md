# LCM And GCD

## Problem Information
- **URL:** https://www.geeksforgeeks.org/problems/lcm-and-gcd4516/1
- **Topic:** 01_Basics
- **Difficulty:** Easy

## Approach & Logic
Use Euclidean algorithm via math.gcd to find GCD. LCM = (A * B) // GCD.

## Complexity Analysis
- **Time Complexity:** O(log(min(A, B)))
- **Space Complexity:** O(1)
